# Акушерская аналитика

Анализ клинических данных пациенток (232 женщины) для оценки связи приема витамина D и фолиевой кислоты (группы D и F) с течением беременности, исходами родов и здоровьем новорожденных. 

Задача проекта — не просто получить максимум p-value, а выделить клинически значимые различия на фоне шума и статистических погрешностей.

## Данные

Исходный файл: `Общая таблиц(2).xlsx` (выгрузка из медицинской базы). Ноутбук загружает его по прямой raw-ссылке, дополнительная подготовка в Colab не требуется.

Структура данных:
- Демография, акушерский и гинекологический анамнез.
- Соматическая коморбидность (ССС, МВС, ЖКТ, эндокринная, ЦНС).
- Осложнения беременности и родов (ПЭ, ГСД, ЗРП, ПИОВ).
- Сроки родоразрешения.
- Показатели крови матери и новорожденного (Hb, тромбоциты, лейкоциты).
- Для группы D — данные по химиотерапии с датами смерти или последнего наблюдения.

**Важный нюанс предобработки:** у части матерей было несколько детей. Чтобы избежать фиктивного увеличения выборки и завышения значимости тестов, все показатели усреднены по матери (одна женщина = одно наблюдение). Без этого шага все p-value были бы невалидны.

## Методы

Перед выбором теста для каждой переменной проводилась проверка на нормальность (критерий Шапиро-Уилка). 
- Для нормальных распределений: t-тест Стьюдента / Уэлча.
- Для ненормальных: U-критерий Манна-Уитни.
- Для трех групп: ANOVA или критерий Крускала-Уоллиса.

Для категориальных признаков применялся критерий хи-квадрат Пирсона. При нарушении условий применимости (ожидаемые частоты < 5 более чем в 20% ячеек) редкие категории объединялись либо использовались точный тест Фишера или G-тест. После значимого хи-квадрата считались стандартизированные остатки для выявления конкретных различий.

Для контроля ошибки первого рода при множественных сравнениях применялась поправка Холма. В условиях малой выборки это критически важно.

Помимо p-value рассчитывались размеры эффекта (Cohen's d, rank-biserial r, Phi), чтобы отделить статистическую значимость от клинической.

Для группы D построены кривые Каплана-Мейера по локализациям онкозаболеваний (с учетом цензурирования) и forest plots с 95% ДИ отношений шансов по возрасту.

## Результаты

Проверено около 50 гипотез в 18 блоках, значимыми признаны порядка 8.

- **Возраст.** Группа D статистически значимо старше группы F (с поправкой Холма p = 0.0003). В D преобладают пациентки 31–40 лет, в F — 26–30. Контрольная группа значимо не отличается ни от кого.
- **Срок родов.** Наиболее выраженное различие. Доля срочных родов: D — 65.3%, F — 90.8%, контроль — 96.2% (p < 0.05). Поздние преждевременные роды (34–36 нед): D — 18.1% против 1.3% и 3.8%. Очень ранние (28–31 нед): D — 8.3%, в остальных группах — 0%. В группе D роды происходят значимо раньше.
- **Заболевания ССС.** Группа F — 36.8%, группа D — 11.1% (p_holm = 0.0008).
- **Заболевания ЦНС.** Выявлены только в контрольной группе (8.8%). В D и F — 0% (p_holm = 0.036).
- **Воспалительные гинекологические заболевания.** D — 15.3%, F — 36.8%, контроль — 32.5%. В группе D значимо меньше случаев.
- **Бесплодие.** В группе F выше, чем в D (15.8% против 4.2%). После поправки на множественные сравнения различие не достигло уровня значимости (тренд).

## Отсутствие различий

Вес и рост новорожденных сопоставимы во всех группах (Крускал-Уоллис, p > 0.05). Показатели крови новорожденных (Hb, тромбоциты, лейкоциты) также без значимых различий как по трем группам, так и в схеме D+F vs контроль. Осложнения беременности (ПЭ, ГСД, анемия, ЗРП, ПИОВ) и акушерский анамнез (первобеременные / повторнобеременные) не различаются.

Это важный результат. Если бы группы различались абсолютно по всем параметрам, возникли бы сомнения в качестве данных или рандомизации. Здесь же картина непротиворечива: группы расходятся по материнским факторам (возраст, соматический статус), но базовые характеристики новорожденных одинаковы.

## Анализ выживаемости (Группа D)

Кривые Каплана-Мейера построены по локализациям рака (РМЖ, РЯ, РШМ, РЩЖ, меланома). На графике отображены локализации с n ≥ 5.

Особенность обработки данных: в колонке «дата смерти» встречались как даты, так и текстовые пометки (`–`, `?`, `наблюдается`, `осмотр`). Была реализована логика, различающая реальные даты и цензурированные наблюдения, чтобы избежать потери данных или ошибочной классификации живых пациенток как умерших.

## Ограничения

Выборка составляет 232 человека, что накладывает ограничения на мощность тестов. В отдельных подгруппах (например, по типу химиотерапии или конкретным локализациям рака) может быть 5–10 пациенток, поэтому интерпретировать результаты в таких срезах следует с осторожностью.

Часть сравнений являлись априорными гипотезами (D vs контроль, F vs контроль), часть — exploratory (D vs F, разбивка по типам ХТ). Exploratory-результаты требуют подтверждения на независимой выборке и в ноутбуке помечены соответствующим образом.
